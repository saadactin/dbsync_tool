1. Executive Summary

The DBSync Tool is a comprehensive, enterprise-grade database synchronization system designed to enable seamless data transfer and synchronization between heterogeneous database systems. The system supports both full sync (complete data copy) and incremental sync (delta changes only), with advanced scheduling capabilities, real-time monitoring, comprehensive reporting, and automated notifications.

Key Value Proposition: Eliminate data silos and enable real-time data availability across different database platforms with minimal manual intervention and maximum reliability.

2.1 Functional Requirements

FR-008 REST API Access System shall expose REST APIs for programmatic access to all functionality Medium
FR-009 User Management System shall support user creation, authentication, and role-based access control High
FR-010 Data Transformation System shall support data transformations during sync (filtering, mapping, conversion) Medium
FR-011 Checkpoint Management System shall maintain sync checkpoints for incremental operations with reset capability High
FR-012 Table Selection System shall allow users to select specific tables for synchronization High
FR-013 Data Integrity Verification System shall verify data integrity post-sync with row count validation Medium

3. Module Specifications

3.1 Core Modules Overview

🔌 Connections Module

Location: connections/

Purpose: Manages database connections and connectors for different database types.

Key Components:

  • connectors/base.py - Abstract base class for all database connectors
  • connectors/postgres.py - PostgreSQL connector implementation
  • connectors/mysql.py - MySQL connector implementation
  • connectors/sqlserver.py - SQL Server connector implementation
  • connectors/clickhouse.py - ClickHouse connector implementation
  • connectors/zoho.py - Zoho CRM API connector
  • connectors/factory.py - Connector factory for dynamic instantiation
  • models.py - Connection model and credential storage
  • views.py - Connection CRUD operations and testing
  • forms.py - Connection creation/edit forms with validation

Features:

  • Encrypted password storage using AES-256
  • Connection testing before save
  • Schema and table metadata retrieval
  • Column information extraction

📋 Sync Jobs Module

Location: sync_jobs/

Purpose: Manages sync job configuration, execution, and monitoring.

Key Components:

  • models.py - SyncJob, SyncExecution, TableResult models
  • views.py - Job creation wizard, detail views, execution management
  • api_views.py - REST API endpoints for jobs and executions
  • services.py - Dashboard services and metrics calculation
  • notifications.py - Email notification service
  • reports.py - Report generation services
  • validators.py - Job configuration validation

Features:

  • Multi-step job creation wizard
  • Job pause/resume functionality
  • Real-time execution tracking
  • Per-table sync status and row counts
  • Export execution logs (CSV/JSON)

⚙️ Sync Engine Module

Location: sync_engine/

Purpose: Core synchronization logic and data processing.

Key Components:

  • executor.py - Main sync execution orchestrator
  • full_sync.py - Full synchronization implementation
  • incremental_sync.py - Incremental synchronization logic
  • checkpoint_manager.py - Incremental checkpoint management
  • query_builder.py - Dynamic SQL query construction
  • data_transformer.py - Data transformation during sync
  • transformation_engine.py - Advanced transformation rules
  • data_integrity_verifier.py - Post-sync verification
  • pre_migration_validator.py - Pre-sync validation checks
  • table_handler.py - Table structure management
  • retry.py - Retry logic for failed operations
  • monitoring.py - Execution monitoring utilities
  • timezone_utils.py - Timezone handling for timestamps

Features:

  • Batch processing for large datasets
  • Automatic data type mapping
  • Configurable retry mechanisms
  • Progress tracking and logging
  • WHERE clause filtering support

📅 Scheduler Module

Location: scheduler/

Purpose: Manages scheduled job execution.

Key Components:

  • service.py - Scheduling service implementation
  • tasks.py - APScheduler task definitions
  • beat_schedule.py - Schedule configuration
  • cron_parser.py - Cron expression parsing
  • utils.py - Scheduling utilities

Features:

  • Flexible scheduling (once, hourly, daily, weekly, cron)
  • APScheduler-based lightweight scheduling
  • Next run time calculation
  • Schedule pause/resume

👥 Accounts Module

Location: accounts/

Purpose: User authentication and management.

Key Components:

  • models.py - Custom user model (if extended)
  • views.py - Login, logout, user management views
  • forms.py - User creation and update forms
  • services.py - User management services

Features:

  • User CRUD operations
  • Role-based access control
  • Admin-only user management
  • Password security with Django validators

📊 Metadata Module

Location: metadata/

Purpose: Database metadata extraction and API endpoints.

Features:

  • Schema listing API
  • Table metadata extraction
  • Column information retrieval
  • Primary key detection

🎯 Core Module

Location: core/

Purpose: Shared utilities and base configurations.

Features:

  • Base mixins and utilities
  • Common exception handling
  • Shared constants
  • Logging configuration

5. System Architecture

5.1 High-Level Architecture

The DBSync Tool follows a layered architecture pattern:

  • Presentation Layer: Web UI (Django Templates + Bootstrap)
  • API Layer: Django REST Framework endpoints
  • Business Logic Layer: Sync Engine, Services, Validators
  • Data Access Layer: Django ORM, Database Connectors
  • Infrastructure Layer: APScheduler, PostgreSQL Control DB

5.2 Data Flow

  1. Job Creation: User creates sync job via web UI with source/target connections
  2. Configuration Storage: Job configuration stored in PostgreSQL control database
  3. Execution Trigger: Job execution triggered (manual or scheduled)
  4. Task Queuing: APScheduler queues the sync task
  5. Sync Execution: Sync engine executes the synchronization operation
  6. Progress Logging: Progress and results logged to database
  7. Notifications: Email notifications sent on completion/failure
  8. Result Display: Results displayed in web UI with detailed metrics
