Data Dictionary / Table Structure

Connections Table

Attribute Name Data Type Constraints Description
id Integer PK, Auto-increment Unique identifier for the connection.
name Varchar(100) Not Null Friendly name for the connection.
type Varchar(50) Not Null Database type (PostgreSQL, MySQL, SQLServer, ClickHouse, Zoho).
host Varchar(255) Nullable Hostname or IP address of the database server.
port Integer Nullable Port number for the database connection.
username Varchar(150) Nullable Database username.
password_encrypted Text Nullable Encrypted database password.
database_name Varchar(150) Nullable Name of the database/schema.
extra_params JSON Nullable Additional connection parameters (e.g., SSL settings).
is_active Boolean Default True Status of the connection configuration.

Sync Jobs Table

Attribute Name Data Type Constraints Description
id Integer PK, Auto-increment Unique identifier for the sync job.
name Varchar(100) Not Null Name of the sync job.
source_connection_id Integer FK to Connections Reference to the source database connection.
target_connection_id Integer FK to Connections Reference to the target database connection.
sync_type Varchar(20) Not Null Type of sync: 'Full' or 'Incremental'.
schedule_cron Varchar(100) Nullable Cron expression for scheduled execution.
table_mapping JSON Not Null Configuration of tables to sync and their mappings.
status Varchar(20) Default 'Idle' Current operational status of the job.
last_run DateTime Nullable Timestamp of the last execution.

Sync Executions Table

Attribute Name Data Type Constraints Description
id Integer PK, Auto-increment Unique identifier for the execution record.
job_id Integer FK to SyncJobs Reference to the sync job being executed.
start_time DateTime Not Null Timestamp when the execution started.
end_time DateTime Nullable Timestamp when the execution finished.
status Varchar(20) Not Null Outcome: 'Success', 'Failed', 'Partial'.
total_rows_processed Integer Default 0 Total number of rows processed across all tables.
log_file_path Varchar(255) Nullable Path to the detailed execution log file.

Table Results Table

Attribute Name Data Type Constraints Description
id Integer PK, Auto-increment Unique identifier for the table result.
execution_id Integer FK to SyncExecutions Reference to the parent execution.
table_name Varchar(150) Not Null Name of the table that was synced.
status Varchar(20) Not Null Outcome for this specific table.
rows_synced Integer Default 0 Number of rows successfully synced.
rows_failed Integer Default 0 Number of rows that failed to sync.
error_message Text Nullable Error message if the table sync failed.

Users Table

Attribute Name Data Type Constraints Description
id Integer PK, Auto-increment Unique identifier for the user.
username Varchar(150) Unique, Not Null User's login name.
email Varchar(254) Unique, Not Null User's email address.
password_hash Varchar(128) Not Null Securely hashed password.
role Varchar(20) Not Null User role (SuperAdmin, Admin, Operator, Viewer).
is_active Boolean Default True Designates whether this user should be treated as active.
date_joined DateTime Default Now Timestamp when the user account was created.
